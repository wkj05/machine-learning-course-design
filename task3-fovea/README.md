# 任务三：眼底黄斑中心凹定位

给定一张眼底照片，回归黄斑中心凹（Fovea）的像素坐标 (X, Y)。评价指标 **RMSE**（越小越好），按官方口径把 20 组 X/Y 共 40 个值算均方根。规则另规定「若图像中黄斑中心凹不可见，坐标值设为 (0, 0)」。

| 项目 | 数值 |
|---|---|
| 训练集 | 80 张（含 XML 标注框，但框中心与 CSV 精确点仅差 2.4 px，无额外信息） |
| 测试集 | 20 张 |
| 图像尺寸 | 2992×2000（85 张）与 1956×1934（10 张） |
| 排行榜最好成绩 | **13.5**（RMSE） |
| 本机留一法 | 平均 15.23 px / 中位数 7.05 px / **RMSE 18.9** |

---

## 一、方法

### 两级结构

1. **第一阶段：整图热图粗定位**
   长边 letterbox 缩放到 1024，ConvNeXt-Tiny（`features_only`，取 stride ≥ 8 的三级特征）接 FPN 头，输出 stride 8 的 128×128 热力图；用 soft-argmax 取亚像素坐标。

2. **第二阶段：1:1 裁块精定位**
   以第一阶段输出为中心，从原分辨率裁 256×256 图块，轻量 U-Net 输出 stride 4 的 64×64 热图，soft-argmax 得到相对裁块中心的偏移。

最终**只用第一阶段**——实测第二阶段在好先验上反而拖后腿（中位数 6.78 → 10.83 px），见下文。

### 训练设计

- 标签：真实坐标转高斯热图（σ=2 个网格单位）。
- 损失：`BCE(热图) + smooth-L1(soft-argmax 坐标, 真值)`，后者把坐标误差直接灌回梯度。
- 折数：5 折交叉验证；推理做 4 向翻转 TTA（模型用 GroupNorm，无跨样本统计量，翻转安全）。
- 时间预算：脚本按剩余时间自动压缩每折 epoch，**宁可每折少跑几个 epoch 也要把 5 折都跑完**（集成的收益大于单模型多训）。

## 三、关键诊断：瓶颈在粗定位，不在精定位

把「几何先验误差」分档后统计细化后的误差：

| 先验误差 | 张数 | 细化后平均 |
|---|---|---|
| 0~30 px | 14 | 12.72 |
| 30~60 px | 35 | 17.14 |
| 60~100 px | 18 | 31.10 |
| 100~155 px | 13 | 62.78 |

先验 < 60 px 的 49 张单独看，RMSE 已达 **15.13**（榜首档）；先验 ≥ 60 px 的 31 张 RMSE 42.03，**占全部平方误差的 83%**。

结论：细化器本质上是「收缩器」不是「检测器」——它的训练标签只落在裁块中心 ±90 px 内，学到的是「在中心附近微调」，因此当前先验偏出 100 px 时它几乎不动。这也解释了为什么淘汰细化器后分数反而跳升 5.7 分。

## 四、被证伪的方向（都做了实测）

| 方向 | 结果 |
|---|---|
| 加宽细化器视野（CROP 256→320） | 精度全面下降，连「先验<30」那档也从 12.72 掉到 38.09 |
| 9 假设滑窗聚类 | RMSE 38.58，比基线差；聚类会挑错吸引子 |
| 多尺度推理（1152 / 1280） | 中位数略降但最大值从 140 炸到 292，净亏 |
| 视盘否决（峰离视盘 <350 px 则改用几何估计） | 80 张只触发 1 张，等于无效；最差 8 张离视盘都有 600~920 px |
| 翻转分歧稳健化 | 留一折仅 +0.05，属于噪声 |
| 两视图/四候选共识融合 | 29.6~30.7，全都不如单模型 |

## 六、复现

```bash
# 本机（需要 GPU 与 timm 预训练权重）
python t3_local.py

# Kaggle：把 t3_kaggle.py 整个粘进一个 code cell，GPU T4 x2 + Internet On，
# 并挂载 2026task3 数据集即可，预算默认 480 分钟
```

脚本会自动寻找数据根目录（同时含 `fovea_localization_train_GT.csv` 与 `train/` 的目录），并打印：

```
[S1 留一法先验] mean=... median=... p90=... max=... | RMSE=... | bias dX=... dY=...
候选文件: submission_s1 / submission_s1_robust / ...
[check] 通过（0 错误 0 警告）
```

`submission.csv` 是留一法最优的那个候选；其余候选也会各写一份，便于对比。
